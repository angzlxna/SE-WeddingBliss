# Client-Server-Anwendung zur Hochzeitsverwaltung

Studienprojekt zur Umsetzung einer Client-Server-Anwendung zur Verwaltung von Hochzeitsgästen und deren Essenspräferenzen.

---

## Überblick
Dieses Projekt entstand im Rahmen eines Moduls im Bereich Software Engineering.
Die ursprüngliche Entwicklung erfolgte in einem universitätsinternen GitLab.
Zur besseren externen Nachvollziehbarkeit wurde das Projekt hier auf GitHub dokumentiert.

---

## Features
- Verwaltung von Hochzeitsgästen und deren Essenspräferenzen
- Client-Server-Kommunikation über JSON
- Persistente Speicherung der Daten über den Server
- Grafische Benutzeroberfläche zur Dateneingabe und -verwaltung

---

## Technologien
- Java
- Spring Boot
- Java Swing
- JSON
- Eclipse

---

## Projektkontext
- Art: Studienprojekt
- Arbeitsform: Gruppenprojekt
- Zeitraum: 2024
- Fokus: Client-Server-Architektur, Datenmodellierung, Schnittstellenkonzepte

## Hinweise
- Die Anwendung wurde lokal ausgeführt.
- Der Fokus des Projekts lag auf der Konzeption einer sauberen Architektur, der Umsetzung einer Server-Client-Schnittstelle sowie der strukturierten Verarbeitung von Daten.
